# Generic AOS Test Framework

Generic test automation framework for AOS components on KVM simulator — startup, config deployment, snapshot extraction, diagrams, archiving.

## When to Use

create test project, start simulator test, validate test setup, pack test results, initialize test from spec

## Capabilities

- Framework commands — init, validate, start, run, pack, clean
- Test method validation — call chain tracing before every test (MANDATORY)
- OpenSpec test specifications — structured test spec format and workflow
- Project folder structure — standardized layout for test projects
- DUT prompt patterns — per-platform model regex patterns
- SSH host key management — automated key acceptance rules
- Background operations policy — async simulator and build management
